# 债务登记分册（docs/debt/）

> 本目录是 `docs/architecture-rules.md` 第 8 节债务登记表的分册。第 8 节保留「债务名 | 所属文件 | 一句话红线」的索引表；完整条目（状态、基线数值、验证命令、完整红线）按关注域放在本目录。

| 分册 | 覆盖范围 | 条目数 |

> 相邻登记：契约与实现之间的已知偏差（错误码映射、哨兵包装缺失）不在本目录，登记在 `contracts/errors.yaml` 的「实现偏差」节，修复后由该节自行删除。

## 条目格式

每条债务固定四个字段：

- **状态**：`已修复`、`已统一`、`存量`。标为存量的条目适用基线只减不增。
- **基线**：当前实测数值与统计口径，含不计入统计的例外。
- **验证命令**：可直接执行的命令，或指向 `docs/architecture-rules.md` 的对应小节；命令必须写清执行目录与排除规则。
- **红线**：触碰相关区域时必须遵守的约束。

## 维护纪律

1. **基线只减不增**：任何改动使基线恶化（新增违例文件、新增实例化点、新增重复代码）即判定违规。
2. **修复即登记**：修复一条债务须在同一变更内更新三处——本目录对应条目（状态与基线）、第 8 节索引表、`docs/architecture-rules.md` 第 9 节的分期状态。
3. **不得以提交信息替代登记**：债务状态只以本目录与第 8 节为准。
4. **新增债务**：先判断归属分册，按上述四字段写入对应文件，再补第 8 节索引行；无合适分册时新增分册并更新本文件的分组表。
5. **验证命令必须实测**：写入前实际执行一次并确认输出与基线一致；执行目录或排除规则变化时必须写进条目，否则会产生假绿。
